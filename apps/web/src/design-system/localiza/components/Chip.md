# Chip

Filtro ou tag compacta — grupos de carro, categorias de destino.

**O consumidor fornece:** `children`, `selected`, `onClick`; opcionais `size` (`md` 32px · `sm` 24px) e `icon`.

Raio `radius-pill`. Repouso: branco com borda `neutral-border-low`. Selecionado: `primary-emphasis-lower` com borda `primary-default` e texto `primary-emphasis-higher` (9,7:1). Use `aria-pressed` (o componente já faz).
