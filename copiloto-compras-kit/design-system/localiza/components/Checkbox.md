# Checkbox

Escolha independente de sim/não, como opcionais e proteções da reserva.

**O consumidor fornece:** `label`, `checked`/`onChange` (ou `defaultChecked`), `disabled`.

20px, borda 2px `neutral-border-high`, raio `radius-sharp` (4px). Marcado: `primary-default` com check `primary-contrast-auto`. Para escolhas mutuamente exclusivas use radio (ainda não no sistema).
