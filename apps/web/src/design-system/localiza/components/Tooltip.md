# Tooltip

Rótulo curto que explica um elemento ao passar o mouse ou focar.

**O consumidor fornece:** `content` (uma frase curta) e o gatilho focável em `children`; `open` força a exibição.

Fundo `neutral-surface-default-inverse` (#4a4a4a), texto branco 14px, raio `radius-sharp`. Nunca coloque informação essencial só no tooltip (não existe em toque).
