# 4. Processo de cotação

> Manual de Compras de Peças de Reposição (fictício, para fins didáticos).

## 4.1 Mínimo de cotações

Compras acima de R$ 2.000,00 exigem pelo menos 3 cotações respondidas no pedido antes da emissão da ordem de compra. Abaixo desse valor, uma cotação válida basta, mas comparar mais de uma é recomendado.

## 4.2 Validade e cotação pendente

Toda cotação tem data de validade informada pelo fornecedor. Cotação pendente ainda não foi respondida e não pode ser escolhida. Só cotações respondidas e dentro da validade entram na comparação.

## 4.3 Cotação expirada é vetada

Cotação expirada não pode ser usada para emitir ordem de compra, mesmo que o preço seja bom. Se o fornecedor for interessante, solicite uma nova cotação a ele.

## 4.4 Como solicitar nova cotação

Solicite nova cotação quando não houver cotações válidas suficientes, quando todas as cotações violarem a política ou quando o mínimo de cotações não for atingido. Priorize fornecedores com boa nota que ainda não cotaram o pedido. A nova cotação entra como pendente até o fornecedor responder.

## 4.5 Empate técnico entre cotações

Quando duas cotações ficam muito próximas na avaliação (diferença menor que 5% na nota consolidada), ou quando os critérios apontam vencedores diferentes, a escolha é do comprador. Sistemas de apoio devem apresentar as opções lado a lado, sem decidir sozinhos.
